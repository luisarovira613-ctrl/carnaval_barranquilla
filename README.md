Carnaval de Barranquilla

Este proyecto corresponde a un sitio web desarrollado como parte de la fase de publicación web del curso de Programación Web.

Descripción

El sitio web está inspirado en el Carnaval de Barranquilla y contiene información relacionada con esta festividad cultural, incluyendo diseño visual, estructura web y contenido multimedia.

Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git y GitHub

Publicación del proyecto

El proyecto fue publicado utilizando GitHub Pages.
